- **Processing:**
  - Read file.
  - Identify priority = High.
  - Create summary.
- **Outputs:**
  - Summary report.
  - Email notification.
- **Suitable for automation?** Yes.
- **Approach:** Hybrid.
- **Reason:**
  - Python can process the CSV data.
  - Power Automate can distribute notifications.
